# LeKiwi ROS2 통합 구현 완료 요약

## 완료된 작업 개요

LeKiwi 로봇의 Isaac Sim + ROS2 완전 통합이 완료되었습니다. 총 4개의 새로운 패키지와 포괄적인 문서화가 완성되었습니다.

## ✅ Priority 1: 핵심 기능 (100% 완료)

### 1. lekiwi_hardware 패키지
**위치**: `src/lekiwi_hardware/`

**구현 내용**:
- Isaac Sim과 ROS2 컨트롤러를 연결하는 하드웨어 추상화 계층
- 베이스(3개 휠)와 암(6개 관절) 명령 분리
- RELIABLE QoS 사용하여 Isaac Sim과 통신

**주요 파일**:
- `hardware_interface.py` (175줄)

**토픽**:
```
구독:
  /joint_states (sensor_msgs/JointState) - Isaac Sim에서
  /base_commands (sensor_msgs/JointState) - 베이스 휠 명령
  /arm_commands (sensor_msgs/JointState) - 암 관절 명령

발행:
  /joint_command (sensor_msgs/JointState) - 통합 명령 → Isaac Sim
```

### 2. lekiwi_command_arbiter 패키지
**위치**: `src/lekiwi_command_arbiter/`

**구현 내용**:
- 우선순위 기반 명령 중재 시스템
- 키위 드라이브 역기구학 내장
- 명령 타임아웃 처리 (0.5초)

**주요 파일**:
- `command_arbiter.py` (215줄)

**우선순위 레벨**:
```
255 - 비상 정지 (PRIORITY_EMERGENCY)
200 - 원격 조작 (PRIORITY_TELEOP)
150 - 매니퓰레이션 (PRIORITY_MANIPULATION)
100 - 내비게이션 (PRIORITY_NAVIGATION)
  0 - 대기 (PRIORITY_IDLE)
```

**토픽**:
```
구독:
  /emergency_stop (std_msgs/Bool)
  /cmd_vel_teleop (geometry_msgs/Twist)
  /arm_command_teleop (sensor_msgs/JointState)
  /cmd_vel_nav (geometry_msgs/Twist)

발행:
  /base_commands (sensor_msgs/JointState)
  /arm_commands (sensor_msgs/JointState)
```

### 3. 오도메트리 퍼블리셔
**위치**: `src/lekiwi_base_control/lekiwi_base_control/base_controller_node.py`

**구현 내용**:
- 키위 드라이브 순기구학 (휠 속도 → 베이스 속도)
- 실시간 오도메트리 적분
- 공분산 행렬 포함
- TF 브로드캐스트

**추가된 기능**:
- `_compute_base_velocity()`: 순기구학
- `_update_odometry()`: 포즈 적분
- `_publish_odometry()`: /odom 발행 및 TF 브로드캐스트

**토픽**:
```
구독:
  /cmd_vel (geometry_msgs/Twist)
  /joint_states (sensor_msgs/JointState) - 실제 휠 속도

발행:
  /odom (nav_msgs/Odometry)
  TF: odom → base_plate_layer1_v5
```

## 빠른 테스트 가이드

### 1. 빌드
```bash
cd /home/vpraise/workspace/lerobot_ros2
colcon build --symlink-install
source install/setup.bash
```

### 2. 환경 설정
```bash
export ROS_DOMAIN_ID=10
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
```

### 3. Isaac Sim 설정
```python
# Isaac Sim Python 콘솔
from lekiwi_isaac_bridge import setup_omnigraph
setup_omnigraph.main()

# 그 후:
# 1. Action Graph 에디터 열기
# 2. ArticulationController의 targetPrim을 /World/LeKiwi로 설정
# 3. PublishJointState의 targetPrim을 /World/LeKiwi로 설정
# 4. Play 버튼 클릭
```

### 4. ROS2 노드 실행
```bash
# 터미널 1
ros2 launch lekiwi_bringup lekiwi_sim_bringup.launch.py

# 터미널 2
ros2 run lekiwi_hardware hardware_interface

# 터미널 3
ros2 run lekiwi_command_arbiter command_arbiter

# 터미널 4 (선택)
ros2 run lekiwi_base_control base_controller_node
```

### 5. 테스트
```bash
# 로봇 이동
ros2 topic pub /cmd_vel_teleop geometry_msgs/Twist \
  "{linear: {x: 0.1}, angular: {z: 0.0}}" --once

# 오도메트리 확인
ros2 topic echo /odom

# TF 트리 확인
ros2 run tf2_tools view_frames
```

## 토픽 맵

### Isaac Sim ↔ ROS2
```
/joint_states      Isaac Sim → ROS2  (RELIABLE)
/joint_command     ROS2 → Isaac Sim  (RELIABLE)
/clock             Isaac Sim → ROS2  (DEFAULT)
```

### ROS2 내부 토픽
```
명령 입력:
  /emergency_stop       Bool
  /cmd_vel_teleop       Twist (우선순위 200)
  /cmd_vel_nav          Twist (우선순위 100)
  /arm_command_teleop   JointState (우선순위 150)

중재 후:
  /base_commands        JointState (휠 속도)
  /arm_commands         JointState (암 명령)

하드웨어 출력:
  /joint_command        JointState (통합)

상태 피드백:
  /joint_states         JointState (Isaac Sim)
  /odom                 Odometry (계산됨)
  TF: odom → base_link
  TF: base_link → links
```

## 키위 드라이브 파라미터

```
휠 배치: 0°, 120°, 240° (균등 배치)
휠 반지름: 0.055m
베이스 반지름: 0.25m
로봇 반지름: 0.30m (충돌 체크용)

역기구학 (Twist → 휠 속도):
  w_i = (1/r) * (-sin(θ_i)*v_x + cos(θ_i)*v_y + R*ω_z)

순기구학 (휠 속도 → Twist):
  v_x = (r/3) * Σ(-sin(θ_i)*w_i)
  v_y = (r/3) * Σ(cos(θ_i)*w_i)
  ω_z = (r/3R) * Σ(w_i)
```
